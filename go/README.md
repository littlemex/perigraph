Written from `SPEC.md` and its normative `spec/vocabularies.json`. Requires Go 1.22 and uses only the standard library.

`FromRequest` makes a partial-safe harness record from a decoded JSON object. An allocated empty map represents `{}`; a nil map represents a JSON `null` body. Use `FromRequestValue` when the decoded body might not be an object. Use `FromRequestJSON` when the original JSON text is available, including when detecting canonical-value failures that a decoder could hide. A missing or `null` top-level request field means the sender supplied none; malformed fields and non-object bodies are reported through detailed `extraction_failed` absences rather than by withholding the record.

The OpenAI Chat Completions binding reads `generation_controls` and `decoding` at the normative `canonical_value` boundary. Generation controls refine an instruction-based harness identity; neither controls nor a request template establish one without an instruction. `response_format` supplies generation controls, not `readout`; the latter is an owner-declared rule, not a request field. An object-body record reports unlisted top-level member names and their omitted count, but not their values. `CanonicalJSON` serialises JSON text under the version 4 canonical-value rules.

Attach the `ModelHalf` returned by `Loaded` when collecting in the process that loaded the model, then call `ToAttributes`. The model digest functions require observations of the loaded artifact and runtime; they do not read files or discover packages on the caller’s behalf.

Run tests with `go test ./...`. When the module is inside the spec repository, the tests also compare the SHA-256 of the embedded vocabulary with `../spec/vocabularies.json` and check the canonical-value fixture. See `AMBIGUITIES.md` for remaining interpretations and API limitations.
