# Code of conduct

Be straightforward and be accurate. Those two carry nearly all of it here.

**On accuracy specifically**, because this project is about records that can be relied on: do not claim a measurement
you did not take, do not round a number toward the point you are making, and if you find you were wrong say so plainly
in the thread where you said it. A retracted claim costs a sentence; an unretracted one costs whatever somebody built
on it. The project's own ledger contains a withdrawn figure and the reason it was withdrawn, and that is the standard.

**On disagreement**, particularly about the spec: two people reading one sentence differently is a defect in the
sentence. Argue about the sentence, not about the reader.

Unacceptable: harassment, personal attacks, and any form of discrimination. A maintainer will remove comments and,
where needed, people.

Report a problem by opening an issue, or privately by saying in a one-line issue that you would like to be contacted.
